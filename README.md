# Instagrão — só viagens

Uma versão temática de um feed do Instagram, feita em React, onde só cabem viagens: destinos, trilhas, praias, roteiros e histórias de pessoas que adoram explorar o mundo.

## Rodar localmente

```bash
npm install
npm run dev
```

## O projeto

- Layout responsivo com navegação, stories de viajantes, sugestões e publicações de destinos.
- Curta e salve posts, abra comentários e publique os seus.
- Busque por perfil, legenda ou destino.
- Perfis, textos, imagens e comentários iniciais ficam em `src/data/posts.json`.

As imagens de demonstração são carregadas do Unsplash. Para usar imagens locais, salve os arquivos em `public/images` e atualize os campos `avatar` e `image` no JSON com caminhos como `/images/minha-foto.jpg`.
